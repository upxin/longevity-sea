# 本地阅读器

双击同一文件夹里的 `index.html`，用浏览器打开即可。无需安装依赖，也无需联网。

- 左侧下拉菜单选书，目录可以直接跳到章节或小节。
- 顶部不占正文空间；底部和正文末尾都有上一章、下一章。
- 键盘左右方向键翻章。手机窄屏下，左上角按钮展开目录。
- 章节地址保留在网址的 `#` 后面，可以用浏览器收藏夹保存某一章。
- 每本书会自动记住当前章节和正文位置。切换书籍后再回来、刷新或重新打开页面，都可以接着读；点击目录或上一章、下一章则从所选章节开头阅读。

阅读记录保存在当前浏览器的本地数据里。同一浏览器、同一地址或文件打开方式下可以续读；更换浏览器、换电脑、切换本地文件与网页地址不会同步记录，清除网站数据也会清除进度。如果浏览器禁止保存，目录底部会显示“进度暂未保存”。

共整理了《九州缥缈录》六册、《龙族》旧版七册及《龙族Ⅴ》。前两套使用现有 EPUB 的原书目录与正文，龙族Ⅴ使用现有 TXT；重复的 TXT、PDF、MOBI 和 AZW3 没有重复列入书架。原始文件未改动。

`index.html`、`reader.css`、`reader.js`、`library.js`、`books` 和 `images` 需要放在一起。可以复制整个“阅读器”文件夹，在另一台电脑离线阅读。

如替换了原书文件，在终端运行下面的命令重新生成数据：

```sh
python3 build.py
```

脚本用 Python 标准库提取现有两套 EPUB 和龙族Ⅴ TXT，不会上传文件。EPUB 中正文续页会合并进对应章节，插图和版权信息随原书保留。缺字或版本差异以选用的源文件为准。
